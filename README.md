# 🎓 Exam Proctoring System

A modern full-stack web application built using **Python Flask** and **SQLite** for conducting online examinations. The system provides secure authentication, quiz management, AI-assisted question generation, PDF question upload, real-time exam experience, and result analytics.

---

## ✨ Features

- 🔐 Secure User & Admin Authentication
- 👨‍💼 Admin Dashboard
- 📝 Create & Manage Exams
- ➕ Manual Question Addition
- 🤖 AI Question Generation using Google Gemini
- 📄 PDF Question Upload
- ⏱️ Real-Time Quiz Timer
- 📊 Automatic Result & Analytics
- 🏆 User Ranking & History
- 📱 Responsive User Interface

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/albinbince10-create/exam-proctoring-system.git
```

### 2. Open the Project

```bash
cd exam-proctoring-system
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Create a `.env` file

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

### 5. Initialize the Database

```bash
python init_db.py
```

### 6. Run the Application

```bash
python app.py
```
